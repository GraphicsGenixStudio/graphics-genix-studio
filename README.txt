GRAPHICS GENIX STUDIO — PHOTO TEMPLATE EXPANSION BUILD

This build expands the editable Photo templates library with contemporary photo-first layouts and category variety: interiors, flowers, gardens, gym, football, running, basketball, tennis, cycling, skincare, beauty, coffee, bakery, restaurant, pets, coast, mountains, city nights, architecture, workspace, product lifestyle, weddings, friends, creative portfolio, and fashion campaigns.

Template cards use curated Unsplash photo previews and therefore need an internet connection to display those preview images. The editor photo areas are replaceable with your own uploaded images. This project does not include Canva's proprietary template library; these are original template concepts for Graphics Genix Studio.

PUBLISHING
1. Back up your existing GitHub repository.
2. Extract this ZIP.
3. Copy the contents of this folder into the repository root, replacing the existing site files.
4. Commit and push to GitHub Pages.
5. After deployment, hard-refresh the website if the old cached version appears.

QA NOTE
JavaScript syntax and ZIP integrity were checked. A full interactive browser test could not be completed in this environment. Please verify opening a template, editing text, replacing a photo, undo/redo and exporting in your browser before treating it as a fully validated public release.
